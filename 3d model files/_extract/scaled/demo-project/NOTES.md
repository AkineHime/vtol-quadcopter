# VTOL Quad-Plane Notes

- Recreated from `plane.jpg` as a multi-file, multi-body KCL assembly.
- The single perspective image provides no physical dimensions, so scale is proportionally inferred.
- The full assembly is uniformly scaled by `1500 / 3040 = 0.493421` from the original geometry.
- Main-wing span is now 1500 mm; the original 590 mm lift rotors scale to approximately 291 mm, and the rear pusher scales to approximately 210 mm.
- Major components remain separate: fuselage, wing panels, tail panels, fins, lift booms, support pylons, motor pods, masts, propellers, landing struts, antennas, probe, and access panels.
- A known dimension or orthographic drawing can be used later to calibrate the model to an exact airframe scale.
