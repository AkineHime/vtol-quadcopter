Coconut VTOL · phone setup

This phone will stream its rear camera to the ground station as the drone camera. Stay on the same Wi-Fi as the laptop.

1Trust the ground station (once)

Install its certificate so the camera page opens without a security warning. Skip this if you are happy to tap through the warning each time.

Download certificate
Android
  1. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate (the path varies a little by phone; search Settings for "CA certificate").
  2. Tap Install anyway, pick coconut-ground-station-ca.crt from Downloads.
iPhone
  1. Open this page in Safari, tap Download certificate, then Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings: turn on Coconut VTOL ground station local CA.
2Start the camera

Allow camera access when asked, hold the phone camera-down like the drone's nose camera, and keep the screen on.

Open camera
3Colour cards (optional)

Hold a coloured shape on white paper in view when the drone reaches a palm: green = tender, light green = young, yellow = mature, brown = over-mature. The dashboard logs it for that palm.
