# aero/ — real airfoil-derived aerodynamics

Replaces the placeholder coefficients that were in the JSBSim model with
numbers derived from the actual **SD7037** (wing) and **NACA 0009** (tail)
airfoils, and sizes the vertical fin / tail incidence.

## Run it

```bash
wsl -d Ubuntu-24.04
source ~/venv-ardupilot/bin/activate
cd "/mnt/e/proggramming/semester proj/aero"
python analyze.py
```

Needs: `aerosandbox`, `numpy`, `scipy`, `matplotlib` (all in the venv).

## What's here

| file | what |
|---|---|
| `airfoils/SD7037.dat` | UIUC/Selig coordinates |
| `airfoils/NACA0009.dat` | generated by `gen_naca.py` |
| `analyze.py` | the whole pipeline (2D polars → 3D coefficients → trim → fin sizing) |
| `control_authority.py` | do the wing elevons alone give enough pitch + roll authority (fixed tail)? → `control_authority.json` |
| `polars/*.csv` | 2D section polars, one per (airfoil, Re) — from NeuralFoil |
| `coefficients.json` | every number, machine-readable; `jsbsim_block` = what went into the XML |
| `RESULTS.md` | human-readable summary + the trim/fin-sizing findings |
| `plots/aircraft_polars.png` | 3D C_L / C_D / C_m vs α |

## Tooling note

XFOIL 6.99 (Debian package) SIGFPEs on every real section on this machine and
AVL 3.36's plot library won't build headless, so this uses **NeuralFoil**
(XFOIL-trained surrogate) for 2D and **AeroSandbox** (AeroBuildup + VLM) for
3D. Same physics, scriptable. XFLR5's GUI is not needed — see
`documents/airframe_tail_airfoil_decision.md` §6.

## Headline findings

- SD7037 @ Re 1.9e5: a₀ 6.2/rad, α₀ −3.3°, Cd,min 0.009, Cl,max 1.30 @ 13° (soft).
- 3D: C_Lα 5.32, C_L0 0.43, C_D0 0.020, k 0.071, C_mα −1.67 /rad, NP 60% MAC.
- **Wing incidence 2° → 1°**, cruise **16 → 12 m/s** (2° trimmed at negative α).
- **Tail incidence −1.8°** vs fuselage (was a −1.5° guess), CG 33% MAC, SM ~27%.
- **Vertical fins undersized** — current V_V 0.027 gives C_nβ ≈ +0.02; need
  **340 cm² total (V_V 0.044)** for C_nβ ≥ 0.07. New fin built in
  `models/freecad/vertical_fin.FCStd`.
- **Elevon authority is abundant** (not marginal): trim uses 1–8% of travel,
  roll ~650 °/s at full throw, pull-up 2.6 g (stall-limited). No tail elevator
  needed; ArduPilot rate/throw limiting expected. (`control_authority.py`)
- **Forward motor**: DJI E305 stand-in swapped for A2212 2200KV + 1045 (the
  real hardware). Cruise throttle now ~0.34. Static NaNs — JSBSim
  brushless-motor limitation. See `flight_software/jsbsim/PROPULSION_NOTES.md`.
