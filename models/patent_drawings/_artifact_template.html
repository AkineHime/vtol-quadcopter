Reading these drawings

Every figure comes from the same 3D point set, so all seven are mutually consistent — a part in the same place across figures, as an examiner expects. Two kinds of dimension went into it:

Confirmed dimension Schematic placeholder

Confirmed: 1.3 m wing span, 288/173 mm root/tip chord, 0.30 m² wing area, unswept leading edge, 28%-chord elevon hinge, 170 cm² per vertical fin, 254 mm (10×4.5″) propellers — all pulled directly from the aerodynamic analysis and control-authority study. None of this is a manufacturing CAD model; it's a drafting-accurate placeholder for the parts that were never designed in detail.

Viability & what's still needed

Viable now

  • All seven standard views, mutually consistent, from one model — achievable entirely from data already on hand, no new engineering required.
  • Reference numerals and leader lines matching a specification's part list.
  • Re-rendering at any camera angle or with different callouts in minutes, since the whole set is generated from one parametric script.

Needed before a final filing

  • Engineer the schematic parts — pod shape, boom length/placement, horizontal-tail sizing, motor mounts — so every dimension in the drawings is confirmed, not placeholder.
  • A true hidden-line CAD render once those parts are engineered, for exact occlusion between parts (this set approximates it).
  • Formal sheet formatting — India Patent Rules margins, sheet numbering, one figure per sheet or a fixed layout — applied once the content is final, not before.
  • Sign-off from whoever drafts the claims on which features the drawings must show, since claim language usually drives what gets drawn and how it's labelled.
